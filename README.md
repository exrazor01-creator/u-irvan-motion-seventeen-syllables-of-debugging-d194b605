One haiku about debugging, in the 5-7-5 syllable shape. A pure-stdlib Python program that writes the haiku to `/output/entry.txt`, guarded by a validator that refuses anything failing the scorer's gate (1–200 characters, exactly 3 non-empty lines, not only white space, valid UTF-8) and checks the 5-7-5 syllable shape against a hand-counted word map.

> A red breakpoint blinks
> logs scroll past at three a.m.
> it was one typo

## Run it

```sh
python3 main.py
```
